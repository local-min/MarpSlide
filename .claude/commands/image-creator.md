以下の説明に基づいて SVG イラスト / ビジネス図表を作成する: $ARGUMENTS

## 共通制約

1. 最大サイズ: 幅 600px x 高さ 400px
2. プロジェクトカラーパレットのみ使用:
   - Navy: #1B4565（主要要素、ヘッダー）
   - Navy Light: #2A5F8F（副次要素、セカンダリ）
   - Teal: #3E9BA4（アクセント、ハイライト、強調）
   - Teal Light: #5BC0C8（軽めのアクセント、バッジ）
   - Slate: #64748B（テキスト、ラベル）
   - Dark Gray: #334155（本文テキスト）
   - Light Gray: #94A3B8（薄いボーダー、補助テキスト）
   - Warm Gray: #F5F5F0（背景パネル）
   - White: #FFFFFF（カード背景）

3. タイポグラフィ:
   - font-family: 'Helvetica Neue', Arial, sans-serif
   - ラベルテキスト: 12-14px
   - タイトルテキスト: 16-18px
   - 大型数値: 24-32px, font-weight: bold

4. スタイル:
   - 角丸の矩形（rx="8"）をボックスに使用
   - ドロップシャドウなし（フラットデザイン）
   - 要素間に十分な余白（最低 20px）
   - ボーダーの線幅: 2px

5. ファイルを `assets/svg/` にわかりやすいファイル名で保存する

6. Marp での埋め込み用 Markdown を出力する:
   `![説明](./assets/svg/ファイル名.svg)`

7. サンプルデータで生成した場合は SVG 内にコメントで `<!-- 要差し替え: 実データに置き換えてください -->` と記す

## 対応する図表タイプ

### A. ビジネス図表（6種）

**A1. ファネル図**
- 上から下へ段階的に幅が狭まる台形バー
- 各段階に名前と数値を表示
- 最上段=最大幅(560px)、下に行くほど幅を狭める
- 段階間の矢印は不要（形状で流れを示す）
- 色: 上から Navy → Navy Light → Teal → Teal Light の濃淡グラデーション

**A2. SWOT 図**
- 2x2 グリッド（各セル 270x170px 程度）
- S(Strengths)=Teal背景, W(Weaknesses)=Slate背景(薄), O(Opportunities)=Navy Light背景, T(Threats)=Light Gray背景
- 各セルに見出し + 箇条書き（最大3項目）
- 中央に十字線（Navy, 2px）

**A3. マトリクス図（2x2ポジショニング）**
- X軸・Y軸の2軸（Navy, 2px, 矢印付き）
- 軸ラベルを四辺に配置
- 象限に項目をドット（circle r="8"）+ ラベルで配置
- 自社ポジションは Teal で強調（r="12"）、他は Slate

**A4. 組織図**
- 上から下へのツリー構造
- ボックス: 白背景、Navy ボーダー
- トップ: Navy 背景、白テキスト
- 接続線: Slate, 1.5px
- 各ボックスに名前 + 役職（小テキスト）

**A5. ロードマップ図**
- 横方向のフェーズブロック（3-5フェーズ）
- 各フェーズ: 角丸矩形、上にフェーズ名、中にマイルストーン箇条書き
- 現在フェーズ: Teal 背景（白テキスト）、他: Warm Gray 背景
- フェーズ間に矢印コネクタ

**A6. バリューチェーン図**
- 横方向の矢印形状（chevron）を連結
- 主活動: 横一列の chevron（Navy 系）
- 支援活動: 上部に横長バー（Slate 系）
- 各要素にラベル

### B. データビジュアライゼーション（5種）

**B1. 縦棒グラフ**
- X軸: カテゴリ、Y軸: 数値（目盛り付き）
- バー: Navy（メイン）, Teal（比較用セカンド系列）
- 軸線: Light Gray, 1px
- グリッド線: Light Gray, 0.5px, 破線
- バー上部に数値ラベル

**B2. 横棒グラフ**
- Y軸: カテゴリ（左寄せラベル）、X軸: 数値
- バー: Navy → Teal のグラデーション or 単色
- バー右端に数値ラベル

**B3. 円グラフ / ドーナツグラフ**
- SVG `<path>` の arc で描画
- 色: Navy, Teal, Navy Light, Teal Light, Slate の順で割り当て
- 凡例: 右側または下部にカラーボックス + ラベル + パーセンテージ
- **円弧の計算方法:**
  ```
  startAngle = 累積パーセンテージ × 360 × π/180
  endAngle = (累積 + 当該) × 360 × π/180
  x1 = cx + r × cos(startAngle)
  y1 = cy + r × sin(startAngle)
  x2 = cx + r × cos(endAngle)
  y2 = cy + r × sin(endAngle)
  largeArcFlag = (当該パーセンテージ > 50%) ? 1 : 0
  <path d="M cx,cy L x1,y1 A r,r 0 largeArcFlag,1 x2,y2 Z" />
  ```
- ドーナツ: 内側に白い円を重ねる（半径 = r × 0.55）

**B4. 折れ線グラフ**
- X軸: 時間/カテゴリ、Y軸: 数値
- 線: Navy（2px）、ドット: Teal（circle r="4"）
- 複数系列: Navy + Teal で色分け
- グリッド線: Light Gray, 破線
- `<polyline>` で描画、fill="none"

**B5. 進捗バー**
- 横長の角丸矩形（背景: Warm Gray）
- 進捗部分: Teal（完了）/ Navy（進行中）
- パーセンテージラベルを右端に表示
- 複数項目を縦に並べる場合は各行にラベル + バー

### C. 概念イラスト（6種）

**C1. 概念図（抽象的な関係性）**
- 中央に主要概念（大きめの角丸矩形、Navy 背景）
- 周囲に関連概念（小さめ、白背景 + Navy ボーダー）
- 接続線 + ラベルで関係を示す

**C2. ベン図**
- 2-3 個の円を重ねて配置
- 各円: 半透明（opacity="0.2"）+ Navy/Teal/Navy Light のストローク
- 重なり部分に共通要素のテキスト
- 各円の外側にラベル

**C3. サイクル図（循環プロセス）**
- 円形に配置した 3-6 個のノード
- 時計回りの矢印で接続
- 各ノード: 角丸矩形、白背景
- 矢印: Teal, 曲線（arc）

**C4. ピラミッド図**
- 三角形を水平に 3-5 段に分割
- 最下段=最大幅、最上段=最小幅
- 色: 上から Navy → Navy Light → Teal → Teal Light（上が濃い）
- 各段にラベル（中央揃え、白テキスト or Dark Gray）

**C5. ネットワーク図**
- ノード: circle r="20-30", Navy 塗り（中心）/ 白塗り + ボーダー（周辺）
- エッジ: Slate, 1.5px の直線
- 各ノード付近にラベル
- 力学モデル不要。手動で均等配置

**C6. アイコンイラスト**
- シンプルな SVG パスによるアイコン（モノクロ or 2色）
- 線幅: 2px、stroke-linecap="round", stroke-linejoin="round"
- アイコン + テキストラベルの組み合わせ
- 用途: スライド内のビジュアルアクセント

## 使用スキルの判断基準

以下の基準で `svg-creator` と `image-creator` を使い分ける:

| コンテンツ | 使用スキル |
|-----------|-----------|
| アーキテクチャ図、フローチャート、シーケンス図 | svg-creator |
| ファネル、SWOT、マトリクス、組織図、ロードマップ | image-creator |
| 棒グラフ、円グラフ、折れ線グラフ | image-creator |
| ベン図、サイクル図、ピラミッド、ネットワーク図 | image-creator |
| 比較図、階層ツリー | svg-creator |
