$ARGUMENTS のスライドファイルをレイアウト問題の観点からチェックし、修正する。

手順:
1. 対象スライドファイル $ARGUMENTS を読み込む
2. HTML にエクスポートして構造を確認する:
   実行: npx marp --html "$ARGUMENTS" -o /tmp/marp-layout-check.html
3. エクスポートした HTML を読み込み、以下の問題を検出する:
   - スライド境界を超えるコンテンツ（720px の高さに収まらない要素）
   - gap や overflow 処理のないグリッド/フレックスコンテナ
   - width/height 制約のない画像（max-w, max-h クラスの欠落）
   - コンテナをオーバーフローする可能性のある長いテキスト
   - コンテンツが収まらないほど狭いカラム（4列以上のレイアウト）
   - 不足しているスペーシングクラス
4. 検出した問題に対して修正を適用する:
   - 画像オーバーフロー → max-h-64 や max-h-80、object-contain を追加
   - テキストオーバーフロー → overflow-hidden やフォントサイズ縮小
   - グリッドオーバーフロー → gap 縮小やカラム数削減
   - リストオーバーフロー → 最大5項目に削減、またはスライド分割を提案
   - 長い単語 → break-words クラスを追加
5. 修正内容を報告する

slides/example.md のパターンを参考に、適切なレイアウトへの修正を提案すること。
