$ARGUMENTS のスライドファイルをスタイルガイドに基づいてレビューし、違反を修正する。

手順:
1. docs/style-guide.md を読み込み、現在のスタイルルールを把握する
2. slides/example.md を読み込み、承認済みレイアウトパターンを確認する
3. 対象スライドファイル $ARGUMENTS を読み込む
4. 以下の違反をチェックする:
   - 承認済みパレット外のカラー（Navy #1B4565, Teal #3E9BA4 等以外）
   - スライドタイトルのコロン（:）
   - テキスト中の感嘆符（!）
   - 装飾的な絵文字
   - 1スライドに3色以上のアクセントカラー
   - 1スライドに6個以上の箇条書き
   - Tailwind CDN スクリプトブロックの欠落
   - frontmatter の math: katex の欠落（数式使用時）
   - 見出し階層の違反（h2なしのh3等）
   - `<div>` 内 Markdown の空行ルール違反
5. 違反を検出したら、コンテンツの意味を保ったまま修正する
6. 変更内容のサマリーを報告する

レイアウトの再構成やコンテンツの意味変更は行わないこと。
