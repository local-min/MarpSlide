# スライドスタイルガイド

## 1. デザイン哲学

- クリーンで知的、落ち着いた美しさ
- アクセントカラーは控えめに使用し、コンテンツを引き立てる
- 1スライド = 1つの明確なメッセージ
- 装飾ではなく、タイポグラフィのサイズと色の濃淡で視覚的階層を表現

## 2. カラーパレット

| 名前 | HEX | 用途 |
|------|-----|------|
| Navy | `#1B4565` | 主要アクセント、見出し、強調背景 |
| Navy Light | `#2A5F8F` | 副見出し、ホバー状態 |
| Teal | `#3E9BA4` | アクセント、ハイライト、コールアウト、データポイント |
| Teal Light | `#5BC0C8` | バッジ、タグ、軽めのアクセント |
| Slate | `#64748B` | 本文テキスト代替、控えめなラベル |
| Dark Gray | `#334155` | デフォルト本文テキスト |
| Light Gray | `#94A3B8` | キャプション、脚注、ボーダー |
| Warm Gray | `#F5F5F0` | スライド背景、パネル背景 |
| White | `#FFFFFF` | カード背景、コントラスト領域 |

### カラールール

- 1スライドあたりアクセントカラーは最大2色（通常 Navy + Teal）
- 背景: 通常スライドは White または Warm Gray、タイトル/セクション区切りは Navy
- 純粋な黒（#000000）はテキストに使わない。Dark Gray（#334155）を使用
- グレートーンは補助要素に、アクセントカラーはキーポイントにのみ使用

## 3. タイポグラフィ

| 要素 | スタイル | サイズ | 色 |
|------|---------|--------|-----|
| スライドタイトル (h1) | Bold | 1.8-2.2rem | Navy / White（暗い背景） |
| セクション見出し (h2) | Semibold | 1.3-1.5rem | Navy / Slate |
| 本文テキスト | Regular | 1.0-1.1rem | Dark Gray (#334155) |
| コードブロック | Monospace | 0.85rem | ライトグレー背景 |
| キャプション/脚注 | Regular | 0.75rem | Light Gray (#94A3B8) |

- 行間: 本文 1.5、見出し 1.2
- フォントスタック: `'Helvetica Neue', Arial, 'Hiragino Kaku Gothic ProN', 'Noto Sans JP', sans-serif`

## 4. ライティングルール

- タイトルにコロン（:）を使わない
- 感嘆符（!）を使わない
- 装飾的な絵文字を使わない（図解中の機能的な絵文字は可）
- 落ち着いた知的なトーンを保つ
- 箇条書きは文の断片でも可
- 1スライドあたり箇条書きは最大5個

## 5. レイアウトルール

- アスペクト比: 16:9（1280x720px デフォルト）
- コンテンツパディング: スライド端から最低40px
- 要素間スペース: 16-24px
- マルチカラムは最大5列
- 画像には max-height 制約を付ける（オーバーフロー防止）
- SVG図表: 最大 600x400px、プロジェクトカラーパレットを使用

## 6. KaTeX 数式規約

- frontmatter に `math: katex` を必ず宣言
- インライン数式: `$x^2 + y^2 = r^2$`
- ブロック数式（重要な数式、中央配置）: `$$E = mc^2$$`
- 永続マクロには `\gdef` を使用（`\def` はローカルスコープ）
- 過度に複雑なネスト式は避け、複数ブロックに分割
- 数式内カラー: `\color{#3E9BA4}` でアクセント

## 7. Tailwind CSS 設定

すべてのスライドファイルで以下のボイラープレートを使用:

```html
<script src="https://cdn.tailwindcss.com"></script>
<script>
tailwind.config = {
  corePlugins: { preflight: false },
  theme: {
    extend: {
      colors: {
        navy: '#1B4565',
        'navy-light': '#2A5F8F',
        teal: '#3E9BA4',
        'teal-light': '#5BC0C8',
        slate: '#64748B',
        'gray-warm': '#F5F5F0',
      }
    }
  }
}
</script>
```

`preflight: false` は必須。Marpテーマのデフォルトスタイルを保持するため。

## 8. カテゴリ別ガイドライン

### Research/Academic スライド

- 研究課題は問いの形で簡潔に表現する（疑問文で終える）
- 統計結果はMarkdownテーブルで表示し、有意水準を明示する
- 参考文献は [番号] Author. "Title." Journal, Year. の形式
- 数式が中心のスライドでは文字サイズを適切に調整する
- 実験パラメータは右サイドバーまたはカード内に整理する

### Business/Sales スライド

- 数値は大きく目立たせる（text-3xl 以上）
- ファネルや価格表は上から下、または左から右の自然な流れで配置する
- CTAスライドは Navy 背景で視覚的に区別する
- 顧客の声は斜体の引用として Teal 左ボーダーで強調する
- ロゴ/パートナーグリッドはプレースホルダーとして Warm Gray 背景のボックスを使用する
- SWOT の各象限は色分けする（Navy, Navy Light, Teal, Teal Light の濃淡で2色ルールを維持）

### SVG図表のガイドライン

- ビジネス図表（ファネル、SWOT、マトリクス等）は image-creator スキルで生成する
- 技術図表（アーキテクチャ、フローチャート、シーケンス等）は svg-creator スキルで生成する
- データビジュアライゼーションは実データがある場合は正確にプロットする
- サンプルデータで生成した場合は SVG 内にコメントで「要差し替え」と記す
- パターン選択の詳細は `docs/pattern-guide.md` を参照する
