# スライドスタイルガイド

## 1. デザイン哲学

- **結論先行**: 各スライドの見出しは「アクションタイトル」として結論・示唆を完全な文で記す
- **1 スライド = 1 メッセージ**: 補足証拠（図表・テキスト）は 1 つのメッセージを支える役割に徹する
- **読み込みに耐える密度**: スライドは読んで理解する資料として設計する。コンテンツの 55-65% 対 余白の 35-45% を目安とし、情報不足にならないよう十分な内容を載せる
- **装飾ではなく階層**: タイポグラフィのサイズ・ウェイト・色の濃淡で視覚的階層を表現する
- **すべての視覚要素に意味がある**: 装飾的なグラフィックは使わず、分析を支える図表のみ配置する

## 2. スライド構造（3 ゾーン）

各スライドは以下の 3 ゾーンで構成する。

```
┌──────────────────────────────────────────┐
│  Action Title Zone (上部 12-15%)         │  ← 結論・示唆を完全な文で
│  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ │
│                                          │
│  Body Zone (中央 70-75%)                 │  ← 証拠：図表、テーブル、テキスト
│                                          │
│                                          │
│  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ │
│  Footer Zone (下部 8-10%)                │  ← 出典、ページ番号
└──────────────────────────────────────────┘
```

### アクションタイトルの書き方

- ラベル（「調査結果」）ではなく、結論の文（「リモートワークは個人作業の生産性を 7pt 向上させた」）を書く
- 聴衆がタイトルだけ通し読みしてもストーリー全体が伝わるようにする
- 最大 2 行以内に収める

### フッターゾーン

- データ出典の明記（数値を示すスライドでは必須）
- 形式: `<p class="text-xs text-gray-400 mt-4">出典: 調査名, 年</p>`

## 3. カラーパレット

| 名前 | HEX | 用途 |
|------|-----|------|
| Navy | `#1B4565` | 主要アクセント、見出し、強調背景、表ヘッダー |
| Navy Light | `#2A5F8F` | 副見出し、セカンダリデータ系列 |
| Teal | `#3E9BA4` | アクセント、ハイライト、コールアウト、主データ系列 |
| Teal Light | `#5BC0C8` | バッジ、タグ、軽めのアクセント |
| Slate | `#64748B` | 本文テキスト代替、控えめなラベル |
| Dark Gray | `#334155` | デフォルト本文テキスト |
| Light Gray | `#94A3B8` | キャプション、脚注、ボーダー |
| Warm Gray | `#F5F5F0` | スライド背景（代替）、パネル背景、表の偶数行 |
| White | `#FFFFFF` | カード背景、コントラスト領域 |
| Subtle Border | `#E2E8F0` | テーブル行ボーダー、カードボーダー |

### カラールール

- 1 スライドあたりアクセントカラーは最大 2 色（通常 Navy + Teal）
- 背景: 通常スライドは White または Warm Gray、タイトル / セクション区切りは Navy
- 純粋な黒（#000000）はテキストに使わない。Dark Gray（#334155）を使用
- グレートーンは補助要素に、アクセントカラーはキーポイントにのみ使用
- チャートでは主要データ系列に Teal、比較系列に Navy Light、非強調に Light Gray を使う

## 4. タイポグラフィ

### フォント階層

| 要素 | Tailwind クラス | サイズ | ウェイト | 色 | 行間 |
|------|----------------|--------|----------|-----|------|
| プレゼンタイトル | `text-5xl` | 3rem (48px) | Bold (700) | White（Navy 背景） | 1.2 |
| スライドタイトル (h1) | `text-2xl` | 1.5rem (24px) | Bold (700) | Navy | 1.3 |
| セクション見出し (h2) | `text-xl` | 1.25rem (20px) | Semibold (600) | Navy / Slate | 1.3 |
| サブ見出し (h3) | `text-base` | 1rem (16px) | Semibold (600) | Navy | 1.4 |
| 本文テキスト | `text-sm` | 0.875rem (14px) | Regular (400) | Dark Gray (#334155) | 1.6 |
| 箇条書き | `text-sm` | 0.875rem (14px) | Regular (400) | Slate (#64748B) | 1.5 |
| キャプション / 脚注 | `text-xs` | 0.75rem (12px) | Regular (400) | Light Gray (#94A3B8) | 1.4 |
| 出典表記 | `text-xs` | 0.75rem (12px) | Regular (400) | Light Gray (#94A3B8) | 1.4 |
| 大型数値（KPI） | `text-4xl` | 2.25rem (36px) | Bold (700) | Teal / Navy | 1.1 |
| データラベル（チャート内） | `text-sm` | 0.875rem (14px) | Bold (700) | データ系列と同色 | — |

### フォントスタック

```
'Helvetica Neue', Arial, 'Hiragino Kaku Gothic ProN', 'Noto Sans JP', sans-serif
```

### タイポグラフィルール

- フォントファミリーは最大 2 種類（見出し + 本文）
- Bold は見出しと強調にのみ使用し、多用しない
- 1 スライド内のフォントサイズは最大 3 段階に抑える
- Marp の h2（`##`）をスライドタイトルとして使う（Marp テーマが自動的にサイズ調整）

## 5. レイアウトルール

### 基本寸法

- アスペクト比: 16:9（1280 x 720px）
- Marp テーマ標準パディング: 約 70px 左右、約 78px 上下（デフォルトテーマ）
- コンテンツエリア: 約 1140 x 564px

### 8px グリッドスペーシング

すべての要素間スペースは 8px の倍数で統一する。

| トークン | Tailwind | 値 | 用途 |
|---------|----------|-----|------|
| micro | `gap-1`, `p-1` | 4px | 極小スペーサー |
| xs | `gap-2`, `p-2` | 8px | グループ内要素間 |
| sm | `gap-3`, `p-3` | 12px | 関連アイテム間 |
| md | `gap-4`, `p-4` | 16px | コンテンツブロック間 |
| lg | `gap-6`, `p-6` | 24px | カラム間ガター（2列） |
| xl | `gap-8` | 32px | 特に広い間隔が必要な場合のみ |

### 見出しとコンテンツの間隔

- h2 見出し直後のコンテンツ: `mt-4`（16px）を標準とする
- h3 サブ見出し直後: `mt-1` ～ `mt-2`（4-8px）
- パターン内の要素間: `gap-4` ～ `gap-6`（16-24px）を標準とする
- コンテンツとフッター（出典）の間: `mt-3` ～ `mt-4`（12-16px）

### カラムレイアウト

| パターン | Tailwind | 比率 | 用途 |
|---------|----------|------|------|
| 均等 2 列 | `grid-cols-2` | 50/50 | 比較、対照 |
| 黄金比 2 列 | `grid-cols-3` + `col-span-2` | 67/33 | 主要 + 補足 |
| 逆黄金比 2 列 | `grid-cols-3` + `col-span-2` | 33/67 | パラメータ + 本文 |
| 均等 3 列 | `grid-cols-3` | 33/33/33 | KPI、3 つの柱 |
| 均等 4 列 | `grid-cols-4` | 25 x 4 | メトリクス、チーム |

- 2 列レイアウトのガター: `gap-6`（24px）
- 3-4 列レイアウトのガター: `gap-4`（16px）

### コンテンツ密度ガイドライン

本スライドは「読んで理解する」資料を前提としており、ピッチ資料のような大きな余白は取らない。

- 箇条書きは 1 スライド最大 5 個
- 1 箇条書きは最大 25-30 語
- Body Zone の 70% 以上をコンテンツで埋める（空白が目立つ場合は情報不足を疑う）
- データ重視スライド: テキスト 30% / ビジュアル 70%
- 論点スライド: テキスト 50% / 証拠 50%
- テキスト中心スライド: テキスト 70% / 余白 30%
- カード・パネル内にも十分なテキスト量を持たせ、要約のみで終わらせない

## 6. テーブルデザイン

### 標準テーブルスタイル（コンサル水準）

```html
<table class="w-full text-sm">
  <thead>
    <tr class="bg-navy text-white">
      <th class="px-4 py-3 text-left font-semibold">見出し</th>
      ...
    </tr>
  </thead>
  <tbody>
    <tr class="bg-white border-b border-gray-100">
      <td class="px-4 py-3">データ</td>
      ...
    </tr>
    <tr class="bg-gray-warm border-b border-gray-100">
      <td class="px-4 py-3">データ</td>
      ...
    </tr>
  </tbody>
</table>
```

### テーブルルール

- **ヘッダー行**: Navy 背景、白文字、`font-semibold`、`px-4 py-3`
- **データ行**: 偶数行に Warm Gray (`#F5F5F0`) のストライプ
- **行ボーダー**: `border-b border-gray-100`（1px、薄いグレー）。太い黒ボーダーは使わない
- **セルパディング**: `px-4 py-3`（水平 16px、垂直 12px）
- **強調セル**: Teal Bold で値を強調
- **合計行**: `border-t-2 border-navy` で上部ボーダー、Bold テキスト
- テキスト配置: ラベル列は左揃え、数値列は中央揃えまたは右揃え

## 7. チャート / SVG 図表スタイル

### チャートデザインルール

1. グリッド線は原則削除する（データラベルで代替）
2. チャートの外枠は描かない
3. データラベルがある場合は軸も省略可能
4. 軸ラベルを残す場合は Light Gray で控えめに
5. **推論ベースのタイトル**を付ける: 「年間売上チャート」→「売上は前年比 34% 増加」
6. 主要データ系列は 1 色（Teal）、他はグレーで控えめに
7. 横棒グラフは大きい順にソート
8. 時系列でなければ横棒グラフを優先
9. デフォルト凡例は使わず、直接ラベルを配置

### SVG 図表仕様

- 最大サイズ: 600 x 400px
- プロジェクトカラーパレットを使用
- フォント: `'Helvetica Neue', Arial, sans-serif`
- 背景は白（`#FFFFFF`）
- ビジネス図表は `image-creator`、技術図表は `svg-creator` で生成
- `assets/svg/` に保存

## 8. ライティングルール

- タイトルにコロン（:）を使わない
- 感嘆符（!）を使わない
- 装飾的な絵文字を使わない（図解中の機能的なアイコンは可）
- 落ち着いた知的なトーンを保つ
- 箇条書きは文の断片でも可
- 数値を示す場合は出典を必ず明記する

## 9. KaTeX 数式規約

- frontmatter に `math: katex` を必ず宣言
- インライン数式: `$x^2 + y^2 = r^2$`
- ブロック数式（重要な数式、中央配置）: `$$E = mc^2$$`
- 永続マクロには `\gdef` を使用（`\def` はローカルスコープ）
- 過度に複雑なネスト式は避け、複数ブロックに分割
- 数式内カラー: `\color{#3E9BA4}` でアクセント

## 10. Tailwind CSS 設定

すべてのスライドファイルで以下のボイラープレートを使用:

```html
<script src="https://cdn.tailwindcss.com"></script>
<script>
tailwind.config = {
  corePlugins: { preflight: false },
  theme: {
    extend: {
      colors: {
        navy: '#1B4565',
        'navy-light': '#2A5F8F',
        teal: '#3E9BA4',
        'teal-light': '#5BC0C8',
        slate: '#64748B',
        'gray-warm': '#F5F5F0',
      }
    }
  }
}
</script>
```

`preflight: false` は必須。Marp テーマのデフォルトスタイルを保持するため。

## 11. カテゴリ別ガイドライン

### Research / Academic スライド

- h2 は研究のストーリーラインに沿ったアクションタイトルとする
- 統計結果は Markdown テーブルで表示し、有意水準（p 値）を明示する
- 参考文献は `[番号] Author. "Title." Journal, Year.` の形式
- 数式が中心のスライドでは文字サイズを適切に調整する
- 実験パラメータはサイドパネル（Warm Gray 背景）に整理する

### Business / Sales スライド

- 数値は大きく目立たせる（`text-4xl` / Bold）
- ファネルや価格表は上から下、または左から右の自然な流れで配置
- CTA スライドは Navy 背景で視覚的に区別し、1 つの明確なアクションを示す
- 顧客の声は斜体の引用として Teal 左ボーダー（`border-l-4 border-teal`）で強調
- ロゴ / パートナーグリッドは Warm Gray 背景でプレースホルダーボックスを配置
- SWOT 各象限は色分け（Navy, Navy Light, Teal, Teal Light の濃淡で 2 色ルール維持）

### 共通ルール

- 1 プレゼンテーション 12-20 枚目安
- プレゼン目的（research / business / technical / educational）に応じた構成に従う
- パターン選択は `docs/pattern-guide.md` を参照
